## Brand & Style

This design system embodies high-craft digital engineering fused with dynamic creative expression. Tailored for a software engineering student, web developer, and technical content creator, the visual language balances disciplined architecture with kinetic energy. The aesthetic is modern, minimalist, and tech-forward—avoiding generic template tropes through calculated asymmetry, ultra-clean negative space, and luminous high-energy accents.

### Design Principles
- **Engineering Rigor:** Systematic layout alignments, crisp micro-labels, and monospaced accents communicate technical precision and foundational problem-solving capability.
- **Kinetic Warmth:** A focused electric-orange focal point punctures deep monochromatic canvases, creating an energetic and approachable aura without lapsing into visual chaos.
- **Atmospheric Depth:** Multi-tiered obsidian planes, delicate linear highlights, and soft radial glows introduce tactility and architectural polish to flat digital screens.
- **Editorial Legibility:** Bold typographic scale shifts direct visual momentum through project portfolios, interactive benchmarks, technical essays, and Bento-grid matrices.

## Colors

The system uses a dark-first color strategy grounded in deep carbon, layered with tactile slate tiers, and sparked by radiant amber-orange accents.

### Palette Architecture
- **Primary (`#FF6B00`):** Electric Radiant Amber. Reserved for focal interaction points, active states, progress metrics, and energetic ambient light gradients.
- **Secondary (`#FFA043`):** Sunlit Amber. Used in gradient transitions, secondary tags, and delicate hover outlines.
- **Tertiary (`#242424`):** Elevated Obsidian. Serves as interactive card backgrounds, elevated sheets, and structured container surfaces.
- **Neutral Deep (`#111111`):** Carbon Foundation. The primary dark viewport background, anchoring content with depth and high contrast.
- **Surface Mid (`#1A1A1A`):** Low-contrast structural container fill for secondary layout zones, dividers, and input backgrounds.
- **Text & Contrast Surfaces:** Pure white (`#FFFFFF`) for primary headlines and high-emphasis data points; muted zinc (`#A3A3A3`) for supportive body copy; subdued ash (`#525252`) for structural borders and tertiary metadata.

## Typography

The typographic pairing unites the technological personality of **Space Grotesk** with the balanced humanist legibility of **Plus Jakarta Sans**.

- **Display & Section Headers (Space Grotesk):** Features geometric proportions with mechanical quirks, lending code-first authority to statements, showcase titles, and stat callouts.
- **Editorial & Body (Plus Jakarta Sans):** Highly readable at dense sizes, handling project case studies, code descriptions, and educational articles with natural fluidity.
- **Micro-Labels & UI Badges (Space Grotesk):** Rendered in uppercase or tight tracking for metadata, commit tags, stack categories, and timeline dates.

## Layout & Spacing

Layouts follow a modular, fluid 12-column grid designed specifically to accommodate dense Bento grid dashboards, engineering roadmaps, and full-bleed showcase artifacts.

### Grid & Breakpoints
- **Mobile (< 768px):** 4-column structure with `margin: 1.25rem` and `gutter: 1rem`. Bento cells collapse vertically into continuous interactive stories.
- **Tablet (768px - 1024px):** 8-column layout with `margin-md: 2.5rem` and `gutter: 1.5rem`. Modules pair into dual-column cards.
- **Desktop (> 1024px):** 12-column layout capped at a maximum width of `1280px` centered canvas, utilizing `margin-lg: 4rem` and `gutter-lg: 2rem`.

### Spatial Rhythm
- Layout rhythm adheres strictly to an 8px modular baseline.
- Bento cards employ generous internal padding (`space-lg` to `space-xl`) to establish high breathing room between technical metadata, code previews, and visual media.

## Elevation & Depth

Visual hierarchy uses ambient diffusion, semi-permeable glass backdrops, and subtle luminous outlines rather than dense opaque drop shadows.

### Elevation Hierarchy
- **Level 0 (Base Canvas):** Solid `#111111` backdrop. Subtle underlying radial ambient gradient of primary amber (`rgba(255, 107, 0, 0.04)`) anchored in section corners.
- **Level 1 (Bento Surfaces & Containers):** Flat `#1A1A1A` with a 1px border of `rgba(255, 255, 255, 0.08)`. Translucent blur (`backdrop-filter: blur(12px)`) when hovering over base-level content.
- **Level 2 (Active & Hover Cards):** Surface elevated to `#242424` with a 1px perimeter glow transitioning to `rgba(255, 107, 0, 0.3)`. Grounded by an ambient drop shadow: `0 20px 40px -15px rgba(0, 0, 0, 0.7), 0 0 20px 0 rgba(255, 107, 0, 0.08)`.
- **Level 3 (Modals, Overlays & Sticky Nav):** Glassmorphic surface (`rgba(17, 17, 17, 0.75)` with `backdrop-filter: blur(16px)`), bounded by `rgba(255, 255, 255, 0.12)` and a soft base cast `0 30px 60px -20px rgba(0, 0, 0, 0.9)`.

## Shapes

The interface balances soft industrial geometry with approachable contours, reinforcing a modern software engineering identity.

- **Standard Base Components (`rounded-lg` / 1rem):** Used for input controls, buttons, tech badges, and inline code blocks.
- **Structural Bento Panels (`rounded-xl` / 1.5rem to 2rem):** Used for project cards, analytics snapshots, media containers, and testimonial panels to convey a modern shell design.
- **Interactive Badges & Status Indicators (Fully Rounded):** Pill-shaped indicators (`9999px`) maintain clean separation for tags, category pills, and social link triggers.

## Components

### Buttons
- **Primary CTA:** High-gloss electric amber (`#FF6B00`) background, obsidian text (`#111111`), Space Grotesk 600. Subtle top inner highlight. Hover state activates a radial bloom `0 0 25px rgba(255, 107, 0, 0.45)` with a -1px transform.
- **Secondary / Ghost:** Transparent background with `#242424` fill, 1px perimeter of `rgba(255, 255, 255, 0.1)`, pure white text. Hover triggers perimeter tinting to `#FF6B00`.
- **Icon / Action:** 44x44px circular or 12px rounded square containers with centered glyphs, activating amber backdrops on state toggle.

### Bento Cards
- Rounded multi-tiered cards (`rounded-2xl` / 1.5rem) built on `#1A1A1A` with a 1px border of `rgba(255, 255, 255, 0.07)`.
- Cards incorporate top-right contextual iconography (external link, GitHub repository, video stream indicator) in muted tones that transition to full `#FF6B00` opacity upon hover.
- Backgrounds support subtle noise overlays and clipped radial amber illumination to highlight primary portfolio achievements.

### Chips & Badges
- **Tech Stack Chips:** Dark slate fill (`#242424`), 1px border (`rgba(255, 255, 255, 0.05)`), `Plus Jakarta Sans` typography at 0.75rem. Icon prefix with 6px spacing.
- **Status Indicator:** Pill container with an animated pulsing dot (`#FF6B00` with radiating opacity ping) signaling availability for engineering roles and collaborations.

### Timeline Elements
- Vertical hairline rule in `rgba(255, 255, 255, 0.1)` with active node markers.
- Node anchors utilize an inner carbon dot wrapped in an outer glowing `#FF6B00` ring.
- Milestone blocks feature date ranges formatted in uppercase Space Grotesk alongside high-contrast role and company headings.

### Input Fields
- Monochromatic containers filled with `#1A1A1A`, bordered with 1px `rgba(255, 255, 255, 0.1)`.
- Active focus state removes native outlines and introduces a crisp `#FF6B00` perimeter with a `0 0 0 3px rgba(255, 107, 0, 0.15)` focus ring.
- Placeholder copy rendered in subdued `#525252`, shifting to crisp `#FFFFFF` during user typing.
